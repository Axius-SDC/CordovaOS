# SDCStudio import templates for Cordova OS

These Markdown templates are the sources the Cordova data models were built from in SDCStudio: one shared
component bundle (`01-cordova-bundle.md`) and ten domain models (`dm-*.md`). Upload a template on SDCStudio's
Markdown template import to rebuild that model. The published models and their generated artifacts are in
`app/sdc4/mediafiles/dmlib/`.

They came from the retired SDC_Demo repository (Axius-SDC/SDC_Demo at bc9987c, February 2026), where Cordova OS was
planned. They are kept here unchanged, so they may not reflect later changes made to the models in SDCStudio.
