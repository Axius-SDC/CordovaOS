Civil Registry Governed Record

Type: Cluster

ID: aan7382wp8e2f58m9a2hvmkp

Root data cluster (DMType Item) for a governed civil-registry record in CordovaOS: a person's civil-status events such as births, marriages, and deaths. Wraps the domain's data components with the shared W3C PROV-O Provenance cluster so each record carries its lineage bound alongside its data. Workflow, attestation, parties, and the system audit trail sit in the DMType's native governance slots; access control and retention apply as bound sdcgovernance policy.
