# How Cordova OS was planned

Planning documents from January and February 2026, from the retired SDC_Demo repository (Axius-SDC/SDC_Demo at
bc9987c), kept unchanged for the record. The current demo is described in the top-level README and `DEMO-SCOPE.md`.

- `concepts.md`: the Republic of Cordova, its ten domains, and the demo's goals.
- `the-contagion.md`: the cross-domain demo scenario.
- `SDC_Data_Physics.md`: the foundational philosophy of the Semantic Data Charter.
- `build-playbook.md`: the phase-by-phase build plan, from template authoring to the deployed demo.
