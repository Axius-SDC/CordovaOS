# CordovaOS

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![SDC4](https://img.shields.io/badge/SDC4-Compliant-teal.svg)](https://semanticdatacharter.com)

**A fictional nation's entire government — 10 domains, zero integration code.**

CordovaOS is a self-contained, clone-and-run proof of concept for [SDC4](https://semanticdatacharter.com) (Semantic Data Charter). It models the Republic of Cordova, a fictional island nation, as 10 fully operational government domain applications that share data through a common semantic foundation — no middleware, no API adapters, no ETL pipelines, no data mapping layer. Every domain is a self-describing SDC4 data model, and cross-domain questions are answered by SPARQL against one shared knowledge graph.

Each record is **governance-composed**: alongside its data, every instance carries its own **Provenance** (who/what/where/when it came from) and a structural **Audit** record, bound to the data at the source rather than bolted on afterward.

## Run it locally

You need Docker (or Podman) with the compose plugin, ~6GB free RAM, and Python 3.12 on the host (for data generation only). Then:

```bash
git clone https://github.com/Axius-SDC/CordovaOS.git
cd CordovaOS
make demo
```

`make demo` starts the stack, generates the small demo dataset, and loads it. When it finishes, open **http://localhost:18000/demo/** for the dashboard, "The Contagion" narrative, and the SPARQL explorer.

### Choose your dataset

Generation is fast; **loading is the cost** (each instance is validated and written to both PostgreSQL and GraphDB). Pick the scale you want:

| Command | Dataset | Load time |
|---|---|---|
| `make demo` (default) | ~250 residents, ~1,500 records | a few minutes |
| `make demo-full` | 25,000 residents, ~100,000 records | **hours** (generation is seconds; the load is the slow part) |

`make help` lists all targets. The full 25,000-resident set is the realistic stress test; the small set is the fast proof of concept, and both exercise the identical cross-domain machinery.

The 10 domain apps are already in the repo (auto-discovered on startup), so there is no separate install step — the demo apps light up as soon as the stack is running.

## Domains

All 10 domain apps were generated by [SDCStudio](https://github.com/Axius-SDC/SDCStudio) AppGen from SDC4-compliant data models. They interoperate because every app shares the same SDC4 Reference Model.

| Domain | Description |
|--------|-------------|
| **Civil Registry** | Citizen identity records — National IDs (CIDs) shared across all domains |
| **Vital Statistics** | Birth, marriage, and death certificates |
| **Business Registry** | Business entity registrations with Business Registry Numbers (BRNs) |
| **Property Registry** | Land and property ownership records |
| **Education Record** | Student enrollments, faculty appointments, academic records |
| **Employment Record** | Employment history linking persons to businesses |
| **Tax & Revenue** | Tax filings for individuals and businesses |
| **Maritime Port Authority** | Vessel port calls, crew manifests, cargo manifests |
| **Healthcare Record** | Patient encounters, vitals, lab results, diagnoses |
| **Law Enforcement Record** | Incident reports and case files |

## The Contagion

The centerpiece is a 7-beat crisis narrative that demonstrates cross-domain graph traversal in action:

1. **The Arrival** — A cargo vessel docks at Porto Sereno. A crew member falls ill.
2. **The Diagnosis** — The hospital identifies a novel pathogen.
3. **The Trace** — Contact tracing crosses maritime, civil, employment, and education domains.
4. **The Spread** — University exposure expands the contact network across four tiers.
5. **The Response** — The Provincial Health Officer triggers cross-domain containment.
6. **The Investigation** — Law enforcement opens an incident tied to maritime and health records.
7. **The Resolution** — A complete government profile query shows every touchpoint for the index case.

Every beat is answerable by SPARQL against the shared knowledge graph — no custom integration required.

## SPARQL queries

Seven pre-built queries in `sparql/` demonstrate deterministic cross-domain graph traversal:

| # | Query | Domains traversed |
|---|-------|-------------------|
| 1 | Complete Government Profile | Civil, Healthcare, Vital (shared CID) |
| 2 | Economic Network Analysis | Business, Maritime, Tax (shared business number) |
| 3 | Social Services Identification | Civil, Healthcare |
| 4 | Supply Chain Provenance | Maritime, Business |
| 5 | Family Economic Unit | Civil + any domain carrying the CID |
| 6 | Institutional Impact | Business, Education |
| 7 | Contagion Contact Tracing | Healthcare, Maritime, Law Enforcement, Education |

Cross-domain joins work because the shared components (National ID, City, organization identifier) resolve to the **same SDC4 component across schemas**, and each component's value is carried in the RDF as an RDF-star reified triple — so a value stays interpretable across domains with no integration layer.

## Technology stack

- **Django 5.2** — web framework for all domain applications
- **PostgreSQL** — operational database (JSONB instances)
- **GraphDB** — OWL 2 RL reasoning triplestore for RDF/SPARQL
- **SirixDB** — temporal JSON/XML versioning database
- **Keycloak** — enterprise SSO (OAuth2, OIDC, SAML 2.0)
- **Docker / Podman** — containerized, runs entirely on your machine

## Project structure

```
CordovaOS/
├── Makefile               # clone-and-run targets (make demo / demo-full)
├── app/sdc4/              # Django project with all 10 domain apps
│   ├── docker-compose.yml # local stack (GraphDB, SirixDB, Keycloak, PostgreSQL, Redis)
│   ├── import_data/       # generated XML instances per domain (gitignored)
│   ├── ontologies/        # SDC4 ontology + Reference Model (sdc4.xsd, .ttl)
│   └── mediafiles/dmlib/  # per-domain DM schema library
├── datagen/               # Python synthetic data generators (host-side)
├── models/                # SDC4 data model exports per domain
├── sparql/                # 7 cross-domain SPARQL queries
└── apps_download/         # generated app archives (reference)
```
